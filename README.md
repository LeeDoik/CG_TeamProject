## 폴더 구조

```
CG_TeamProject/
├─ docs/   제안서, 보고서, 발표 자료
└─ src/    소스 코드, 셰이더, 리소스
```

## 협업 규칙

1. `main`은 항상 빌드되는 상태로 유지한다.
2. 작업은 브랜치에서 한다: `feature/기능이름`, `fix/버그이름`
3. 작업 끝나면 Pull Request → 팀원이 확인 후 merge
4. 작업 시작 전에 항상 `git pull` 로 최신 상태 받기
5. 커밋 메시지 예: `feat: 플레이어 이동 구현`, `fix: 텍스처 로딩 오류 수정`, `docs: 제안서 수정`

```bash
git clone https://github.com/LeeDoik/CG_TeamProject.git
git checkout -b feature/player-move
# ... 작업 ...
git add .
git commit -m "feat: 플레이어 이동 구현"
git push -u origin feature/player-move
# GitHub에서 Pull Request 생성
```
