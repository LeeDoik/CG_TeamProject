# 배경 이음새와 3D 바닥 개선

## 원인과 수정

- 산·언덕·숲 조각의 무작위 배치 간격이 그림 너비보다 커져 세로 틈이 생겼다. 조각 너비와 간격을 맞추고, 그림의 좌우 실루엣을 주기적으로 이어 그리도록 수정했다.
- 배경 아틀라스의 셀 경계에서 옆 그림이 섞이지 않도록 UV를 반 텍셀 안쪽으로 옮겼다. 별도 여백이 없는 배경 아틀라스는 밉맵을 사용하지 않는다.
- 3D에서 짧은 배경판 하단이 드러나던 부분에 불투명한 받침 면을 추가했다. 받침 면의 아래쪽 정점을 앞쪽 숲 하단과 같은 화면 높이에 맞춘다. 실제 카메라의 view/projection 행렬을 사용하므로 2D, 3D, 전환 중간과 이동 중에도 적용된다. 원래 산봉우리와 숲의 실루엣은 늘리지 않는다.
- 잔디 윗면에 큰 색 변화, 작은 풀 무늬, 꽃 점과 좁은 흙길을 추가했다. 월드 좌표를 사용해 발판 크기에 따라 무늬가 늘어나지 않는다.
- 발판 안쪽에 작은 풀과 꽃을 배치했다. 가시, 장애물, 시작 위치, 체크포인트, 수집품 주변은 피하고 발판의 가림 처리와 함께 투명해지도록 연결했다.
- 아래쪽 책장의 반복 글줄을 짧은 문단과 식물 삽화로 바꿨다. 잔디 덮개 밑에 숨었던 플레이어 그림자를 실제 보이는 표면 위로 옮겼다.

충돌 상자, 이동 속도, 점프, 전환 시간과 스테이지 데이터는 변경하지 않았다. 장식과 배경 받침 면에는 충돌이 없다.

## 검증

- Visual Studio 2022의 일반 `Debug | x64` 빌드 성공.
- 최종 기준 캡처: `src/Default_Project/Screenshots/baseline-20261111-202415-693/`. 2D·전환 50%·3D의 상태와 촬영 시각을 검사했고, 두 실행의 세 이미지가 모두 바이트 단위로 일치했다. 실제 이미지를 열어 배경 연결, 바닥 표현과 그림자를 확인했다.
- 수정 전 비교 대상: `baseline-20261111-192448-963/`. 최종 폴더의 `comparison-preview.png`에 동일한 시점의 3D 화면을 위아래로 모았다.
- 전체 실시간 자동 플레이는 튜토리얼부터 엔딩까지 HP 3으로 완료했다. 증거는 `src/Default_Project/Screenshots/scenery-playthrough-20261111/`에 있다. 이 실행 이후 배경 하단의 화면 정렬을 추가했으며, 최종 빌드의 별도 이동·밤 배경 검사는 `src/Default_Project/Screenshots/scenery-final-review-20261111/`에 기록한다.
- 최종 빌드에서 이동 중 6장, 밤 배경 5장을 추가로 캡처했다. 앞뒤 전환 중간과 3D→2D 복귀를 확인했으며, 이동 경로와 밤 배경에서도 연결부에 빈 띠가 다시 생기지 않는 것을 이미지로 검토했다.

캡처와 로그는 Git에서 제외되는 로컬 검증 결과다. 성능 향상이나 다른 GPU에서의 픽셀 일치를 주장하는 검사는 아니다.
