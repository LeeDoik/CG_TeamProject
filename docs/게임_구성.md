# 게임 구성 (튜토리얼 ~ 스테이지 3, 2026-11-11)

팀원의 `src/Default_Project` 엔진(컴포넌트·씬·조명) 위에 제안서의 게임 전체를 올렸다.
게임 코드는 `Game/`, 레벨은 `Levels/*.txt`, 셰이더는 `Shader/`, 소리는 `Sounds/`, 자동 플레이 테스트는 `Tests/`에 있다.

## 실행

1. `src/Default_Project/Default_Project.vcxproj`를 Visual Studio로 연다. VS 2026은 `.slnx`를 열어도 된다.
2. **x64 / Debug**로 빌드하고 실행한다(F5).
   - GLEW·GLFW·GLM은 수업 실습과 같은 방식으로 `dependencies/` 폴더와 `OpenGL.props`에서 가져온다. 전역 설치가 필요 없다.
   - VS 2022에서는 툴셋 v143, VS 2026에서는 v145가 자동으로 선택된다.
3. 작업 폴더는 프로젝트 폴더여야 한다(`Shader/`, `Levels/`, `Sounds/`를 상대 경로로 읽는다). VS 기본값이 이미 프로젝트 폴더다.

## 조작

| 키 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| Space | 점프 (짧게 누르면 낮게 뜀, 위에서 밟으면 책벌레 처치) |
| W / S | 깊이 이동 (3D에서만) |
| E | 2D ↔ 3D 전환 (0.5초) |
| ESC | 일시정지 메뉴 (다시 누르면 계속) |
| 마우스 / W·S·방향키 + Enter·Space | 메뉴 버튼 선택 |
| M | 소리 끄기·켜기 |
| R / F1~F4 | 지금 스테이지 다시 / 튜토리얼·스테이지 1~3으로 바로 (테스트용) |
| F12 | 스크린샷 (`Screenshots/shot_N.bmp`) |

## 화면 흐름

타이틀(책 표지, START·QUIT) → 튜토리얼 → 스테이지 1 → 2 → 3 → 엔딩(PAGES 4/4, 클리어 시간, TITLE·QUIT).
조각을 얻으면 STAGE CLEAR 띠가 나오고 2초 뒤 다음 스테이지(HP 회복). HP가 0이면 게임 오버(RETRY·TITLE).
창 제목에는 HP·모드·게이지·조각 수와 구간 힌트(한글)가 나온다. 화면 글자는 5x7 점 글꼴이라 영문 대문자만 쓴다.
타이틀의 "POP-UP BOOK"은 임시 제목이다(제안서상 제목 미정).

## 직접 작성할 부분 (제안서 4.2)

아래는 제안서상 팀원이 직접 작성할 부분인데, 게임을 끝까지 동작시키려고 **AI가 임시로 채웠다**(11/11, 팀원 결정).
면담·발표 전에 직접 다시 작성하고, 아래 클리어 테스트로 같은 결과가 나오는지 확인한다.

| 부분 | 파일 | 지금 AI 임시 코드의 방식 | 확인 방법 |
|---|---|---|---|
| 2D/3D 충돌 규칙 | `CoreRules.cpp` `BoxesOverlap` | 2D는 x·y 구간만, 3D는 x·y·z 구간 비교 (AABB) | 클리어 테스트 통과 |
| 투영 행렬 보간 | `CoreRules.cpp` `BlendProjection` | 직교·원근 행렬 원소별 선형 보간 + 거리에 맞춘 화각(돌리 줌, `GameManager::UpdateCamera`) | `POPUP_CAPTURE`로 전환 도중 프레임 캡처 |
| 2D→3D 깊이 맞추기 | `CoreRules.cpp` `ChooseDepthFor3D` | 2D 기준 발밑 발판을 찾아 지금 깊이가 그 안이면 유지, 아니면 발판 깊이 중심으로 | 튜토리얼 C 가운데 발판 위에서 E → 콘솔 `z 0 → -6` |
| 3D→2D 겹침 검사 | `CoreRules.cpp` `CanReturnTo2D` | 2D 규칙으로 겹치는 발판·벽이 있으면 금지 | 튜토리얼 D 상자 뒤에서 E → `시점 전환 막힘` |
| 반투명 그리기 순서·알파 | `FadeRenderer.*`, `Sprite_fragment.glsl` | 반투명 물체를 모아 먼 것부터 블렌딩, 스프라이트 알파 테스트 | 스테이지 2 벽 뒤 구간을 3D로 캡처 |
| 조명 셰이더 | `Paper_fragment.glsl` | 팀원 `Standard_fragment.glsl` 조명에 텍스처 곱셈만 더함 | 2D/3D 화면 비교 |

## 레벨 파일 형식

```
# 주석
name 스테이지 1          # 창 제목에 나오는 이름
page 2                   # 이 스테이지의 조각 번호
next stage2.txt          # 다음 레벨 (없으면 마지막 → 엔딩)
killY -7                 # 이보다 아래로 떨어지면 낙사
start x y z              # 시작 발 위치
block  x y z  w h d  [재질]                 # 고정 발판 (중심, 크기)
spike  x y z  w h d
mover  x y z  w h d  재질  ax ay az  주기    # 중심 + (ax,ay,az) * sin(2πt/주기)
worm   x y z  범위  속도                     # 발 위치, x±범위 왕복
checkpoint x y z
fragment   x y z
lamp   x y z  밝기                           # 점광원
hint   x시작 x끝 문장                        # 창 제목 힌트
```

좌표는 x 오른쪽, y 위, z 화면 쪽(+)이다. 블록 한 칸이 1이다. 재질 이름: `Paper`, `Card`, `CardDark`, `Wall`, `Mover`.
플레이어는 0.7 × 1.2 × 0.5이고, 점프 높이는 약 2, 점프 거리는 약 3.5다.

## 자동 플레이 테스트

창을 띄우지 않고 입력 스크립트로 플레이한다(레벨이나 `CoreRules.cpp`를 고친 뒤 회귀 확인용). 테스트 중에는 소리가 꺼진다.

```
powershell -ExecutionPolicy Bypass -File Tests\run_replay.ps1 -Replay Tests\clear_all.txt -TimeoutSec 160
powershell -ExecutionPolicy Bypass -File Tests\run_replay.ps1 -Replay Tests\clear_stage2.txt -Level Levels\stage2.txt
```

| 스크립트 | 내용 | 11/11 결과 |
|---|---|---|
| `clear_all.txt` | 튜토리얼 → 스테이지 1 → 2 → 3 → 엔딩 연속 | 조각 4/4, HP 3 유지, 엔딩 도달 |
| `clear_tutorial.txt`, `clear_stage1~3.txt` | 스테이지 하나씩 (`-Level`로 그 스테이지부터) | 모두 클리어 |

움직이는 발판·책벌레는 플레이 시간 기준으로 움직이므로, 레벨 배치나 이동 수치를 바꾸면 스크립트의 시각도 맞춰 고쳐야 한다.

| 환경 변수 | 뜻 |
|---|---|
| `POPUP_HEADLESS=1` | 창을 숨긴 채 실행 (소리도 꺼짐) |
| `POPUP_REPLAY=경로` | 입력 스크립트 재생 (`시간 키 down/up`, `시간 quit`). 키: A D W S E SPACE R M ESC ENTER UP DOWN F1~F4 |
| `POPUP_LEVEL=경로` | 첫 레벨 파일 바꾸기 (타이틀 건너뜀) |
| `POPUP_LOG=1` | 0.25초마다 위치·모드·게이지·HP·가까운 책벌레를 콘솔에 출력 |
| `POPUP_CAPTURE=2.0,5.1` | 그 시각(초)에 자동 스크린샷 |
| `POPUP_CAPTURE_DIR=경로` | 스크린샷 폴더 (기본 `Screenshots`) |
| `POPUP_MUTE=1` | 소리 끄고 시작 |
