# 차원별 충돌·3D 게이지·전환 조건 시험 레벨 (기획서 4.1~4.3)
# 왼쪽(x -4)에서 오른쪽(x 124)으로 구간 A~F. 구간마다 확인할 규칙을 hint 줄에도 적었다(불러올 때 콘솔에 나온다).
# 좌표: x 오른쪽, y 위, z 화면 쪽(+). 바닥 윗면이 y 0, 기본 줄은 z 0.
# block·mover의 x y z는 중심, start·fragment의 y는 바닥(발) 기준이다(레벨 형식 규칙).
# 구덩이에 떨어지면 아래 도랑(윗면 y -3)에 닿는다. 낙사(killY)는 아직 없어서 도랑 끝 계단으로 다시 올라온다.

name 규칙 시험
subtitle RULES TEST
page 1
theme day
killY -10
start 0 0 0

# ---- A. 출발 (x -4 ~ 12): 2D에서 게이지가 차고, E로 2D ↔ 3D를 오간다 ----
block -4.5 2 0 1 4 6 DarkGray
block 4 -0.5 0 16 1 6 DarkGreen
hint -4 12 A: E로 2D와 3D를 오가 보세요. 게이지는 3D에서 5초에 바닥나고 2D에서 2.5초에 찹니다

# ---- B. 2D로만 건너는 다리 (x 12 ~ 24) ----
# 가운데 발판만 안쪽(z -6)에 있다. 2D에서는 한 줄로 이어져 밟히고, 3D에서는 깊이가 떨어져서 못 건넌다.
# 2D로 가운데 발판 위에 서서 E → 플레이어 z가 0에서 -6(발판 깊이 중앙)으로 옮겨진 뒤 3D가 된다.
block 13.5 -0.25 0 3 0.5 2 LightGray
block 17.5 -0.25 -6 5 0.5 2 Blue
block 22 -0.25 0 4 0.5 2 LightGray
# 도랑 바닥과 올라오는 계단 (다리 끝 x 24와 다음 바닥 x 26 사이)
block 19 -3.5 -2 14 1 12 DarkGray
block 25.25 -2.25 -2 1.5 1.5 12 DarkGray
hint 12 26 B: 2D로만 건널 수 있습니다. 가운데 파란 발판 위에서 E를 누르면 그 발판 깊이로 맞춰집니다

# ---- C. 3D로만 지나가는 벽, 2D로 못 돌아가는 상자 뒤 (x 26 ~ 46) ----
# 벽과 상자는 앞줄(z -0.5 ~ 3)에 있고 높이가 3이라 2D에서는 못 넘는다. 3D에서 W로 안쪽(z -2 근처)으로 돌아간다.
# 상자 뒤(x 36 ~ 41, 안쪽)에서 E → 2D로 보면 상자와 겹쳐서 막힌다(화면 0.3초 흔들림). 벗어나면 된다.
block 36 -0.5 0 20 1 6 DarkGreen
block 30.5 1.5 1.25 1 3 3.5 DarkGray
block 38.5 1.25 1.25 5 2.5 3.5 Orange
hint 26 46 C: 벽은 3D로 돌아가세요. 주황 상자 뒤에서는 2D로 돌아갈 수 없습니다

# ---- D. 5초보다 긴 3D 구간 (x 46 ~ 82) ----
# 벽 14칸 + 틈 2.5칸 + 벽 14칸. 한 번에 돌면 게이지가 모자란다. 틈(x 62 ~ 64.5)에서 2D로 돌아가 충전한다.
# 틈에서 충전하지 않고 계속 가면 두 번째 벽 뒤에서 게이지가 0이 되고, 2D로 돌아갈 수 없어서 start로 보내진다.
block 64 -0.5 0 36 1 6 DarkGreen
block 55 1.5 1.25 14 3 3.5 DarkGray
block 71.5 1.5 1.25 14 3 3.5 DarkGray
hint 46 82 D: 벽 사이 틈에서 2D로 돌아가 게이지를 채우세요. 벽 뒤에서 게이지가 바닥나면 처음으로 돌아갑니다

# ---- E. 움직이는 발판 (x 82 ~ 108) ----
# E-1 좌우 발판(진폭 4.5, 4초): 올라타면 같이 움직인다. 도랑 위를 건넌다.
block 89 -3.5 -2 14 1 12 DarkGray
block 95.25 -2.25 -2 1.5 1.5 12 DarkGray
mover 88 -0.25 0 3 0.5 3 Orange 4.5 0 0 4
block 98 -0.5 0 4 1 6 DarkGreen
# E-2 깊이 발판(z 진폭 4, 4초): 2D에서는 언제나 밟힌다. 3D에서는 앞으로 올 때를 기다려야 한다.
block 104 -3.5 -2 8 1 12 DarkGray
block 100.75 -2.25 -2 1.5 1.5 12 DarkGray
mover 104 -0.25 0 4 0.5 2 Purple 0 0 4 4
hint 82 108 E: 좌우 발판에 타면 같이 움직입니다. 보라 발판은 앞뒤로 움직여서 2D에서는 언제나 밟힙니다

# ---- F. 엘리베이터 (x 108 ~ 124) ----
# 위아래 발판(진폭 1.5, 4초)이 윗면 0 ~ 3을 오간다. 올라오는 발판은 플레이어를 들어 올린다.
# 꼭대기에서 오른쪽 선반(윗면 4)으로 뛴다. 바닥(0)에서는 점프(2칸)로 닿지 않는다.
# 조각(fragment)은 위치만 적는 줄이라 y가 바닥 기준이다(레벨 형식 규칙). 선반 윗면 4 위에 놓인다.
block 114 -0.5 0 12 1 6 DarkGreen
mover 116 1.25 0 2 0.5 2 Orange 0 1.5 0 4
block 121 2 0 6 4 6 LightGray
fragment 122.5 4 0
hint 108 124 F: 엘리베이터를 타고 올라가 선반으로 뛰세요
