# 스테이지 1: 발판 계단을 2D로 오르기(책벌레) → 가시 바닥을 3D로 우회 → 체크포인트
#            → 깊이로 왕복하는 발판을 2D에서 밟기 → 긴 벽을 게이지를 나눠 우회 → 조각 2
# 형식 (한 줄에 객체 하나, # 뒤는 주석)
#   block  x y z  w h d  [재질]          고정 발판·벽 (x y z = 중심, w h d = 크기)
#   spike  x y z  w h d                  가시 (닿으면 HP -1, 체크포인트로)
#   mover  x y z  w h d  재질  ax ay az  주기   움직이는 발판 (중심 + 폭 x sin)
#   worm   x y z  범위  속도              책벌레 (x y z = 발 위치, x±범위 왕복)
#   checkpoint x y z / fragment x y z / start x y z / lamp x y z 밝기
#   hint   x시작 x끝 문장                 플레이어 x가 그 사이면 창 제목에 표시
# 좌표: x 오른쪽, y 위, z 화면 쪽(+) / 안쪽(-). 블록 한 칸 = 1
# 플레이어: 0.7 x 1.2 x 0.5, 점프 높이 약 2, 점프 거리 약 3.5, 3D 게이지 5초
