# AI 활용 기록

제안서 4번(AI 활용 계획)과 최종 보고서 5·6번(AI 활용 사례·평가)에 쓰기 위한 기록이다.
AI를 쓴 작업마다 한 줄씩 더한다.

| 날짜 | 작업 | AI(Claude Code)가 한 일 | 직접 판단·작성한 부분 / 남은 일 | 확인 방법 |
|---|---|---|---|---|
| 11/11 | 빌드 환경 | 수업 실습의 `dependencies`·`OpenGL.props` 방식을 팀 프로젝트에 적용하고 VS 2022(v143)에서도 빌드되게 프로젝트 설정 수정 | 팀원 엔진 구조 유지 | VS 2022 MSBuild 빌드 성공 |
| 11/11 | 튜토리얼·스테이지 1 뼈대 | 레벨 파일 로더, 플레이어 이동·점프, 3D 게이지, 적·가시·체크포인트·HP, 추적 카메라, HUD, 레벨 배치, 자동 플레이·스크린샷 테스트 도구 작성 | **직접 작성할 것:** `Game/CoreRules.cpp`의 2D/3D 충돌 규칙, 투영 행렬 보간, 전환 조건 2개 (지금은 임시 코드), 반투명·그림자 알파 처리. 레벨 형식·수치는 플레이해 보고 조정 | 숨긴 창 자동 플레이로 이동·점프·전환·게이지·가시·책벌레·체크포인트·클리어·레벨 다시 불러오기 확인 |
| 11/11 | 2D 충돌 규칙 (임시) | 튜토리얼·스테이지 1 끝까지 클리어 확인을 위해 `BoxesOverlap`에 2D 규칙(z 무시) 작성, 클리어 입력 스크립트(`Tests/clear_*.txt`) 작성 | 팀원이 "이번엔 AI가 임시로 채움"을 선택. **제안서 4.2대로 면담·발표 전에 직접 다시 작성**하고 같은 클리어 테스트로 확인 | `Tests/clear_all.txt` 자동 플레이: 튜토리얼 → 스테이지 1 클리어, 조각 2/4, HP 3 |
